# 계약 — 콘텐츠 파일 형식

이 사이트에 외부로 노출되는 API는 없다. 대신 **사이트 주인이 콘텐츠를 쓰는 형식**이 계약이다.
FR-015("항목 추가·수정이 화면 구성 코드 변경 없이 가능")가 지켜지는지는 이 계약으로 판정한다.

이 계약을 깨는 파일은 빌드를 실패시킨다. 배포된 사이트가 조용히 잘못되는 것보다 낫다.

## 책장 파일

**경로**: `src/content/shelves/<slug>.md`

```markdown
---
name: 프로필
order: 1
description: 저를 소개하는 책들이 꽂혀 있습니다.
emptyMessage: 아직 준비 중입니다.      # 선택
---
```

본문은 쓰지 않는다. 책장은 메타데이터만 갖는다.

## 책 파일

**경로**: `src/content/books/<책장 slug>/<책 slug>.md`

```markdown
---
title: 박종건이라는 개발자
order: 1
spine:
  color: crimson          # 토큰 이름. hex 금지
  height: tall            # short | medium | tall
  width: medium           # narrow | medium | wide
year: "2018—"             # 선택
callNumber: AB · 001      # 선택
summary: 서버와 시스템을 짓는 백엔드 개발자입니다.
---

## 첫 장의 제목

본문을 씁니다. 장 나눔은 화면 크기에 맞춰 브라우저가 처리하므로
여기서 페이지 경계를 지정하지 않습니다.

## 다음 장의 제목

이어서 씁니다.
```

### 책등 색 토큰

`spine.color`에 쓸 수 있는 값은 아래로 제한된다. 각 토큰은 배경과 글자색이 짝으로 묶여 있고,
모두 대비 4.5:1 이상이 확인된 조합이다 (`design-notes.md` 참조). 목록 밖의 값이나 hex는 거부된다.

| 토큰 | 대비 |
|---|---|
| `crimson` | 5.99:1 |
| `walnut` | 9.51:1 |
| `sand` | 6.10:1 |
| `olive` | 7.80:1 |
| `parchment` | 9.56:1 |
| `ink` | 12.27:1 |
| `oak` | 5.81:1 |
| `brick` | 6.78:1 |
| `wine` | 9.66:1 |

## 검증 규칙 (빌드 실패 조건)

| 규칙 | 이유 |
|---|---|
| 책장이 정확히 3개가 아님 | FR-001 |
| `order`가 1·2·3 각 하나씩이 아님 | 방 배치가 결정되지 않음 |
| 책 `slug` 중복 | URL이 `/books/<slug>`로 평평함 |
| 같은 책장 안 `order` 중복 | 책장 내 순서가 결정되지 않음 |
| `spine.color`가 허용 토큰이 아님 | 원칙 V, 그리고 대비 보장 |
| 책 본문이 비어 있음 | 빈 책은 존재할 수 없음 |
| 프로필 책장에 본문 있는 책이 0권 | FR-022 |
| 필수 필드 누락 / 타입 불일치 | 스키마 위반 |

## URL 계약

| 경로 | 내용 | JS 없이 동작 |
|---|---|---|
| `/` | 방. 책장 3개와 책등 | ✓ 모든 책 링크가 평범한 `<a>` |
| `/books/<slug>` | 책 한 권의 전문 | ✓ 정적 페이지 |

방에서 책을 누르면 `/books/<slug>`로 가는 링크를 가로채 모달로 띄우고 주소만 바꾼다 (R-3).
JS가 없거나 실패하면 가로채기가 일어나지 않고 그냥 그 페이지로 이동한다. 두 경우 모두 같은 내용에
도달한다.

**호환성 약속**: `/books/<slug>`는 영구 주소로 취급한다. 책의 `slug`를 바꾸면 공유된 링크가 깨지므로,
바꿀 때는 이전 주소에서 새 주소로 보내는 처리를 함께 넣는다.
