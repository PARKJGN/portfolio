**작성**: 2026-07-21
**대상**: `design/` 에 놓인 Claude Design 산출물
**목적**: 계획(`/speckit-plan`) 단계의 입력. 명세는 기술 중립이어야 하므로 시각·구현 관련 판단은
여기에 모아 둔다.

시안은 레이아웃과 색 참고용이며, 마크업은 새로 작성한다.

## 확정된 결정

1. **시각 방향: 도서관 목재·양피지.** `Portfolio Shelf` 시안의 따뜻한 갈색·베이지 계열을 채택한다.
   Modernist 디자인 시스템은 사용하지 않는다. 두 방향은 양립하지 않는다 — Modernist는 평면·무장식·
   라운드 0·빨강 강조이고, 책장 시안은 입체·질감·명조체다. 헌장 원칙 V(단일 디자인 시스템)를 지키려면
   하나여야 한다.
2. **모바일: 책장 가로 스와이프.** 좁은 화면에서 책장 사이를 옆으로 넘겨 이동한다. 페이지 자체의
   가로 스크롤은 발생시키지 않는다(헌장 제약). 키보드 대체 경로가 반드시 함께 있어야 한다 → FR-018, FR-019.
3. **두 번째 책장 이름은 "프로젝트".**

## 시안에서 그대로 가져올 것

- **책등 색 9종.** 배경/글자 대비를 계산한 결과 5.81:1 ~ 12.27:1 로 전부 AA 기준(4.5:1)을 넘는다.
  이 조합은 손대지 않고 토큰으로 옮긴다.
  - `#ae1800`/`#f3ead5` 5.99 · `#3f2c1a`/`#e8d9bd` 9.51 · `#c7a877`/`#3a2a16` 6.10
  - `#4f4327`/`#efe6cf` 7.80 · `#e3d6b6`/`#3a2a16` 9.56 · `#241a10`/`#e8d9bd` 12.27
  - `#6b5334`/`#f0e6cf` 5.81 · `#7d3b2a`/`#f3e6dc` 6.78 · `#5e2016`/`#efe2c6` 9.66
- **모달 본문** `#463714` on `#f0e6d0` — 9.32:1. 통과.
- 책등을 세로 조판하고 위/아래에 연도·청구기호를 배치한 구성.
- 책장 상단 두꺼운 널판, 단(tier) 구분, 바닥 그림자로 깊이를 주는 방식.
- 장식용 책(`decorTop`, `decorMid`)에 `aria-hidden`을 건 처리 — 그대로 유지한다.

## 시안에서 반드시 고쳐야 할 것

1. **인라인 hex 제거.** 시안은 색·간격을 인라인 스타일에 직접 박아 두었다. 헌장 원칙 V는 리터럴 값을
   금지한다. 모든 값을 이름 있는 토큰으로 옮긴 뒤 참조해야 한다.
2. **글꼴 전략 재수립.** 시안은 한글 글꼴 3종(Nanum Myeongjo, Gowun Batang, Pretendard)을 외부
   CDN에서 불러온다. 두 가지가 문제다.
   - 헌장 원칙 III은 self-host + 서브셋을 요구한다. 한글 글꼴은 글리프 수가 많아 서브셋 없이는
     성능 예산을 맞출 수 없다.
   - `Portfolio.dc.html`은 `font-family: "Archivo", "Pretendard"` 로 되어 있으나 **Archivo에는 한글
     글리프가 없다.** 한국어 사이트에서 라틴 전용 글꼴을 앞에 두면 사실상 폴백으로만 렌더된다.
   - 권장: 본문 한글 글꼴 1종 + 제목용 명조 1종까지로 줄이고, 자체 호스팅 + 서브셋. 계획 단계에서 확정.
3. **반응형 전무.** 시안은 1200px 고정 폭, 책장 간격 96px, 모달 780px로 데스크톱만 상정한다.
   320px 대응 레이아웃을 새로 설계해야 한다.
4. **두 보기 모드 미설계.** 시안 모달은 좌우 2면 펼침 고정이다. 명세의 핵심인
   "한 장씩 넘기기 ↔ 전체 이어보기"(FR-007~FR-011)는 시안에 존재하지 않는다. 계획 단계에서 처음부터
   설계해야 하는 부분이며, 이 기능에서 가장 불확실성이 큰 영역이다.
5. **접근성 누락 3건.**
   - Esc 키로 닫기 없음 → FR-005
   - 모달 포커스 트랩 없음 → FR-013
   - `prefers-reduced-motion` 미대응. `bookPull`(0.5s)과 `coverOpen`(0.7s) 애니메이션이 조건 없이
     재생된다 → FR-016
6. **빨강 강조색의 용도 제한.** `#ec3013`은 양피지 바탕에서 3.39:1이라 본문 크기 텍스트에 쓸 수 없다.
   대형 텍스트·아이콘·테두리에만 쓰고, 본문에는 더 어두운 단계를 쓴다. Modernist DS의 readme도 같은
   제약을 명시하고 있다.
7. **방명록 책장 구조 재검토.** 시안은 방명록 칸에 프로젝트 책을 채워 놓았다(자리 채우기). 방명록은
   글이 쌓이는 성격이라 "책 여러 권"보다 "한 권에 장이 쌓이는" 형태가 맞을 가능성이 높다. 003에서 결정.

## 계획 단계로 넘기는 미해결 질문

- 한 장씩 보기에서 장을 나누는 기준: 콘텐츠에 고정으로 표시할 것인가, 화면 크기에 따라 흘릴 것인가.
  후자면 창 크기 변경 시 읽던 위치 보존 방법이 필요하다.
- 책 열기를 브라우저 방문 기록에 남길 것인가. FR-012(주소 공유)와 뒤로 가기 동작이 여기서 갈린다.
- 방 배경을 이미지로 낼 것인가 화면 구성 요소로 그릴 것인가. 성능 예산과 320px 대응에 모두 영향.
