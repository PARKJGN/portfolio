# 계약: 방명록 API

**Feature**: 003-guestbook | **Date**: 2026-07-31

인그레스에서 `/api` 로 들어온 요청이 이 서비스로 온다. 모든 본문은 JSON, 인코딩은 UTF-8.

오류 응답은 형태가 하나다.

```json
{ "error": "rate_limited", "message": "잠시 뒤 다시 남겨 주세요.", "retryAfter": 240 }
```

`message` 는 **그대로 방문자에게 보여도 되는 문구**다(원칙 II). `error` 는 화면이 분기할 때
쓰는 기계용 값이다.

---

## GET /api/guestbook/entries

공개된 글을 최신순으로 돌려준다. 인증이 필요 없다.

**쿼리**

| 이름 | 타입 | 기본 | 설명 |
|---|---|---|---|
| `limit` | 정수 1–50 | 20 | 한 번에 가져올 수 |
| `before` | ISO 8601 | 없음 | 이 시각보다 이전 글만. 이어 읽기에 쓴다 |

**200**

```json
{
  "entries": [
    { "id": 42, "author": "지나가던 개발자", "body": "3D 책 재밌네요.\n잘 봤습니다.", "createdAt": "2026-07-31T02:11:09.482Z" }
  ],
  "nextBefore": "2026-07-31T02:11:09.482Z"
}
```

- `body` 는 순수 텍스트다. 줄바꿈(`\n`)만 의미를 가진다. 받는 쪽은 **반드시 텍스트로**
  넣어야 한다(`textContent`). HTML 로 해석하면 안 된다.
- 더 가져올 것이 없으면 `nextBefore` 가 `null` 이다.
- `status` 가 `visible` 인 것만 나온다. 보류·삭제된 글은 존재 자체가 드러나지 않는다.

## POST /api/guestbook/entries

글을 남긴다. 인증이 필요 없다.

**본문**

```json
{
  "author": "지나가던 개발자",
  "body": "3D 책 재밌네요.",
  "website": "",
  "openedAt": "2026-07-31T02:10:50.000Z"
}
```

| 이름 | 필수 | 규칙 |
|---|---|---|
| `author` | 예 | 앞뒤 공백 제거 후 1–20자 |
| `body` | 예 | 앞뒤 공백 제거 후 1–500자 |
| `website` | 예 | **항상 빈 문자열이어야 한다.** 사람 눈에 보이지 않는 칸이다(1층 방어) |
| `openedAt` | 예 | 폼이 화면에 나타난 시각. 제출까지 3초 미만이면 사람이 아니라고 본다 |

**201** — 공개됨

```json
{ "status": "visible", "entry": { "id": 43, "author": "…", "body": "…", "createdAt": "…" } }
```

**202** — 보류됨

```json
{ "status": "held", "message": "남겨 주셔서 고맙습니다. 확인한 뒤 보이게 됩니다." }
```

보류 사유는 방문자에게 알리지 않는다. 어떤 규칙에 걸렸는지 알려 주면 우회를 돕는 셈이다.

**오류**

| 상태 | `error` | 언제 |
|---|---|---|
| 400 | `invalid_input` | 길이·필수값 위반. `message` 에 무엇이 문제인지 담는다 |
| 409 | `duplicate` | 24시간 안에 같은 내용이 이미 있다 |
| 429 | `rate_limited` | 시간당 한도 초과. `retryAfter` 초 |
| 503 | `unavailable` | 데이터베이스에 닿지 못함. 방문자가 적던 내용은 화면이 보존한다 |

**봇으로 판정된 요청**(`website` 가 비어 있지 않거나 `openedAt` 이 너무 최근)은 **201 을
돌려주되 저장하지 않는다.** 봇에게 실패를 알려 주면 조건을 바꿔 다시 온다.

## GET /api/guestbook/held

보류된 글 목록. **관리 토큰이 필요하다.**

```text
Authorization: Bearer <관리 토큰>
```

**200**

```json
{
  "entries": [
    { "id": 44, "author": "…", "body": "…", "createdAt": "…", "heldReason": "판정: 광고성", "verdictScore": 0.87 }
  ]
}
```

**401** — 토큰이 없거나 틀림. `error` 는 `unauthorized`.

---

## POST /api/guestbook/entries/:id/publish

보류된 글을 공개한다. 관리 토큰 필요.

- **200** `{ "status": "visible" }`
- **404** 그런 글이 없음 (`not_found`)
- **409** 이미 공개됐거나 삭제됨 (`invalid_state`)

---

## DELETE /api/guestbook/entries/:id

글을 지운다(상태를 `removed` 로). 관리 토큰 필요. 공개된 글과 보류된 글 모두 대상이다.

- **200** `{ "status": "removed" }`
- **404** 그런 글이 없음

---

## GET /api/health

살아 있는지 확인한다. 인증 없음. 쿠버네티스 프로브가 쓴다.

- **200** `{ "ok": true }` — 프로세스가 떠 있고 데이터베이스에 닿는다
- **503** `{ "ok": false }` — 데이터베이스에 닿지 못한다

---

## 공통 규칙

**CORS** — `https://portfolio.jgbak-land.com` 만 허용한다. 같은 도메인의 `/api` 로 들어오므로
평소에는 필요 없지만, 로컬 개발에서 사이트(3000)와 API(포트 다름)가 갈리므로 개발 출처를
환경변수로 하나 더 받는다.

**응답 시간** — 판정(3층)은 외부 호출이라 오래 걸릴 수 있다. 정해진 시간 안에 답이 없으면
기다리지 않고 **보류로 처리해 응답한다**(FR-013 · SC-002). 방문자를 기다리게 하지 않는다.

**로그** — 글 내용을 로그에 남기지 않는다. 남기면 지워도 로그에 남는다.

**정화** — 서버는 받은 텍스트를 그대로 저장한다. 위험을 없애는 것은 저장이 아니라 **표시**
단계다. 받는 쪽이 텍스트로 넣는 한 안전하고, 계약이 그것을 요구한다.
